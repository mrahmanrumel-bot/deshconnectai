# DeshConnect AI — v0.1

বাংলাদেশের নাগরিক সেবার জন্য বাংলা-প্রথম গাইড।

## এখন যা কাজ করে
- ডার্ক ল্যান্ডিং পেজ + অফিসিয়াল লোগো
- চ্যাট UI (`chat.html`)
- স্টার্টার নলেজবেস: NID, পাসপোর্ট, TIN, ভূমি, myGov, জন্ম নিবন্ধন
- সোর্স লিংকসহ উত্তর
- কোনো পেইড API লাগে না

## লোকালে খুলুন
ফোল্ডারের `index.html` ব্রাউজারে খুলুন, তারপর **চ্যাট শুরু করুন**।

## পরে (এখন নয়)
1. Cloudflare Pages / GitHub Pages-এ আপলোড
2. GoDaddy-তে nameserver পয়েন্ট (`deshconnectai.com`)
3. Gemini / Groq ফ্রি কী দিয়ে আসল LLM + RAG

GoDaddy থেকে নতুন প্রোডাক্ট কিনবেন না।
